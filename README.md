# Looker Studio Dashboard

Dashboard interaktif menggunakan Google Looker Studio — bagian dari portofolio 
Data Analyst, memvalidasi analisis dataset Superstore lintas 3 tools berbeda 
(Excel → Python → Looker Studio).

## Live Dashboard
🔗 https://datastudio.google.com/reporting/37a6dc78-8225-48b6-88b7-7b72283dbe2f

## Isi Dashboard
- **Bar Chart** — Total Sales per Region
- **Pie Chart** — Total Profit per Category
- **Table** — Quantity per Segment & Region (2 dimensi)
- **Filter Control** — filter interaktif berdasarkan Region dan Category
- **Scorecard (KPI)** — Total Sales, Total Profit, dan Profit Margin 
  (calculated field: `SUM(Profit)/SUM(Sales)`)

## Dataset
Sample Superstore Dataset (Kaggle) — dataset yang sama dipakai konsisten di:
- [excel-data-analysis](https://github.com/MichaelChan07/excel-data-analysis) 
  (Excel Pivot Table & Dashboard)
- [python-data-analysis](https://github.com/MichaelChan07/python-data-analysis) 
  (Pandas groupby)
- Looker Studio (repo ini)

Tujuannya membuktikan hasil analisis konsisten di berbagai tools, bukan cuma 
menguasai 1 tool saja.
